# 同步坞边界问题与异常场景处理清单

> 版本：v1.0  
> 更新时间：2026-04-06

---

## 一、文档目的

同步坞是本地桌面工具，且直接调度 Git 仓库。该类产品最容易出问题的地方，不是"主流程能否跑通"，而是边界场景是否被提前考虑。

本文件用于整理首版必须提前考虑的边界问题、异常场景和策略建议。

---

## 二、产品边界问题

### 2.1 产品职责边界

**同步坞只负责**：
- ✅ 读取仓库状态
- ✅ 批量执行安全同步
- ✅ 记录结果
- ✅ 输出状态与日志

**同步坞不负责**：
- ❌ 自动修仓库
- ❌ 自动解决冲突
- ❌ 替用户决定分支策略
- ❌ 自动整理未提交修改
- ❌ 远端仓库生命周期管理

### 2.2 用户预期边界

必须在产品文案和说明中明确：

- ⚠️ 同步坞不是"无脑同步一切"
- ⚠️ 同步失败并不总是应用 bug
- ⚠️ 本地有改动时默认会跳过
- ⚠️ 某些问题需要用户手动处理

## 三、路径与文件系统边界

### 3.1 中文路径

| 场景 | 处理策略 | 验证状态 |
|------|----------|----------|
| 路径包含中文 | 正常处理，UTF-8 编码 | ✅ 已验证 |
| 仓库名包含中文 | 正常显示 | ✅ 已验证 |
| 远端 URL 备注含中文 | 正常存储和显示 | ✅ 已验证 |

### 3.2 空格路径

| 场景 | 示例 | 处理策略 | 验证状态 |
|------|------|----------|----------|
| 路径包含空格 | `D:\My Projects\Repo A` | 自动加引号处理 | ✅ 已验证 |

### 3.3 超长路径

| 场景 | 说明 | 处理策略 |
|------|------|----------|
| Windows 长路径 | 超过 260 字符 | 提示用户启用长路径支持或移动到较短路径 |

### 3.4 无权限路径

| 场景 | 处理策略 | 提示信息 |
|------|----------|----------|
| 系统盘受保护目录 | 标记为无权限，跳过 | 无法访问该仓库路径，请检查目录权限 |
| 管理员权限目录 | 标记为无权限，跳过 | 同上 |
| 网络映射盘 | 尝试访问，失败则跳过 | 网络路径不可达 |

### 3.5 路径失效

| 场景 | 处理策略 | 用户操作 |
|------|----------|----------|
| 仓库被用户手动删除 | 标记为失效，不自动移除 | 提示用户重新定位或删除条目 |
| 移动到其他目录 | 标记为失效 | 提示用户更新路径 |
| 外置硬盘未连接 | 标记为失效 | 提示用户连接设备后重试 |

## 四、Git 仓库边界

### 4.1 非标准仓库

| 场景 | 处理策略 | 说明 |
|------|----------|------|
| bare repo | 跳过 | 不支持裸仓库 |
| worktree | 跳过 | 不支持 worktree |
| submodule | 跳过 | 作为独立仓库处理 |
| nested repo | 分别识别 | 内嵌仓库独立识别 |
| detached HEAD | 跳过 | 当前分支异常 |

### 4.2 仓库损坏

| 场景 | 处理策略 | 错误码 |
|------|----------|--------|
| `.git` 不完整 | 标记为损坏，跳过 | SD-REPO-002 |
| 索引损坏 | 标记为损坏，跳过 | SD-REPO-002 |
| refs 异常 | 标记为损坏，跳过 | SD-REPO-002 |
| HEAD 指向非法分支 | 标记为异常，跳过 | SD-REPO-002 |

### 4.3 分支问题

| 场景 | 处理策略 | 提示信息 |
|------|----------|----------|
| 当前分支不存在 upstream | 跳过 | 未配置 upstream，已跳过同步 |
| 当前分支已被远端删除 | fetch 时检测，提示 | 远端分支已删除，请切换分支 |
| 当前分支名特殊 | 正常处理 | 无特殊处理 |
| 本地处于 rebase 中 | 跳过 | 正在 rebase，已跳过 |
| 本地处于 merge 中 | 跳过 | 正在 merge，已跳过 |

### 4.4 远端问题

| 场景 | 处理策略 | 提示信息 |
|------|----------|----------|
| remote 缺失 | 标记为异常 | 未配置远端 |
| origin 不存在 | 标记为异常 | 未配置 origin |
| 配置多个 remote | 使用 origin | 使用默认 origin |
| 默认 remote 不是 origin | 使用配置的默认 remote | 正常处理 |

## 五、同步策略边界

### 5.1 本地有未提交修改

**默认跳过**，但需要明确：

| 情况 | 默认行为 | 可配置 |
|------|----------|--------|
| staged 但未 commit | 跳过 | 否 |
| unstaged changes | 跳过 | 否 |
| untracked files | 可配置跳过 | 是（`skipUntrackedFiles`） |

### 5.2 ahead/behind 同时存在

**场景**：本地和远端都发生变化

**策略**：
- 标记为需要手动处理
- 不自动同步
- 提示用户手动处理分支差异

### 5.3 fast-forward 不成立

**场景**：无法快进合并

**策略**：
- ✅ 首版直接失败
- ❌ 不自动 merge
- ❌ 不自动 rebase
- 提示用户手动处理

### 5.4 fetch 成功但 pull 失败

**要求**：
- 必须记录成明确的两阶段结果
- 不能笼统写"同步失败"
- 日志中分开记录 fetch 和 pull 的结果

### 5.5 rebase/merge 进行中

**检测方式**：
- 检查 `.git/rebase-merge` 或 `.git/rebase-apply` 目录
- 检查 `.git/MERGE_HEAD` 文件

**策略**：
- 标记为高风险仓库
- 直接跳过
- 提示用户先完成或中止操作

## 六、环境与依赖边界

### 6.1 Git 未安装

**检测**：执行 `git --version`

**策略**：
- 应用启动时检测
- 显示阻断型提示
- 提供安装指引链接

**错误码**：`SD-ENV-001`

### 6.2 Git 版本过低

**最低版本要求**：Git 2.0+

**策略**：
- 检测版本
- 提示升级
- 部分功能可能不可用

**错误码**：`SD-ENV-003`

### 6.3 SSH 不可用

**场景**：Git 存在，但 SSH key 未配置或 agent 不工作

**策略**：
- 同步时捕获鉴权失败
- 提示用户检查 SSH 配置

**错误码**：`SD-AUTH-001`

### 6.4 HTTPS 凭证过期

**场景**：Git Credential Manager 凭证失效

**策略**：
- 捕获鉴权失败
- 提示用户更新凭证

**错误码**：`SD-AUTH-002`

### 6.5 代理环境异常

**场景**：公司网络、VPN、代理影响访问

**策略**：
- 捕获网络异常
- 提示检查网络和代理设置

**错误码**：`SD-NET-001` 或 `SD-NET-003`

## 七、性能边界

### 7.1 仓库数量多

| 数量 | 处理策略 |
|------|----------|
| 50 个以下 | 无特殊处理 |
| 50-100 个 | 注意性能优化 |
| 100+ 个 | 首版未充分测试，建议分批管理 |

### 7.2 大仓库

| 场景 | 处理策略 |
|------|----------|
| 对象历史大 | 注意 fetch 超时设置 |
| fetch 较慢 | 增加超时时间配置 |
| status 扫描耗时 | 状态刷新异步执行 |

### 7.3 同时刷新与同步

**策略**：
- 状态刷新和同步任务分离
- 不允许同时执行
- 使用全局任务锁

### 7.4 日志增长过快

**策略**：
- 按天数自动清理（默认 30 天）
- 日志文件大小限制
- 提供手动清理功能

## 八、UI 与交互边界

### 8.1 数据延迟

**场景**：状态更新有延迟时

**策略**：
- 立即显示 loading 状态
- 操作按钮禁用
- 不让用户误判为点击无效

### 8.2 任务中重复操作

| 操作 | 策略 |
|------|------|
| 重复点击同步全部 | 忽略，提示已有任务在运行 |
| 同步中删除仓库 | 允许删除，不影响正在执行的任务 |
| 同步中修改分组 | 允许修改，下次同步生效 |
| 同步中导入配置 | 禁用导入按钮 |

### 8.3 详情与列表不同步

**场景**：仓库状态更新后详情面板未同步

**策略**：
- 详情面板监听仓库状态变化
- 自动更新显示
- 不需要手动刷新

### 8.4 窗口尺寸极端情况

| 场景 | 策略 |
|------|------|
| 超小窗口 | 最小宽度限制（1200px），横向滚动 |
| 高分屏缩放 | 使用相对单位，自适应 |
| 多显示器切换 | 保存窗口位置和大小 |

## 九、建议的异常策略表

| 异常 | 策略 | 错误码 | 用户提示 |
|------|------|--------|----------|
| 路径失效 | 标记失效，不自动移除 | SD-FS-001 | 仓库路径不存在，已跳过 |
| 无 upstream | 跳过 | SD-REPO-003 | 未配置 upstream，已跳过 |
| 本地有改动 | 跳过 | SD-REPO-004 | 存在未提交修改，已跳过 |
| 远端鉴权失败 | 失败 | SD-AUTH-001 | SSH 鉴权失败，请检查配置 |
| 当前处于 rebase 中 | 跳过 | SD-REPO-007 | 正在 rebase，已跳过 |
| 仓库损坏 | 失败 | SD-REPO-002 | 仓库状态异常，请手动检查 |

## 十、需要额外说明的用户教育点

1. **同步坞默认保守**  
   不是所有仓库都会同步，有改动会自动跳过

2. **跳过不等于异常**  
   跳过是保护行为，说明仓库状态不允许自动同步

3. **有些问题必须手动处理**  
   工具不会替用户做危险操作

4. **自动化能力受 Git 本身状态约束**  
   Git 仓库状态决定了能否自动同步

5. **工具不应替用户处理复杂历史分叉**  
   ahead/behind 同时存在需要手动处理
