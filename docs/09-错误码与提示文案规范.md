# 同步坞错误码与提示文案规范

> 版本：v1.0  
> 更新时间：2026-04-06

---

## 一、错误码体系概述

### 1.1 错误码格式

**格式**：`SD-模块-编号`

**示例**：
- `SD-ENV-001` - Git 未安装
- `SD-REPO-004` - 存在未提交修改
- `SD-SYNC-003` - 无法快进拉取

**说明**：
- `SD`：SyncDock 固定前缀
- `模块`：错误分类（ENV/CFG/REPO/SYNC/AUTH/NET/TASK/UI/FS/INT）
- `编号`：三位数字流水号

### 1.2 模块分类

| 模块代码 | 模块名称 | 说明 |
|----------|----------|------|
| ENV | 环境类错误 | Git 环境、系统环境相关 |
| CFG | 配置类错误 | 配置文件、设置相关 |
| REPO | 仓库类错误 | 仓库状态、结构相关 |
| SYNC | 同步类错误 | 同步流程、命令执行相关 |
| AUTH | 鉴权类错误 | SSH、HTTPS 鉴权相关 |
| NET | 网络类错误 | 网络连接、代理相关 |
| TASK | 任务类错误 | 任务调度、状态相关 |
| UI | 界面类错误 | UI 渲染、交互相关 |
| FS | 文件系统类错误 | 文件、目录操作相关 |
| MIG | 迁移类错误 | 配置迁移、导入导出相关 |
| LOG | 日志类错误 | 日志读写相关 |

## 二、错误层级定义

### 2.1 级别分类

| 级别 | 说明 | 示例 |
|------|------|------|
| Info | 信息提示，不表示异常 | 状态已刷新 |
| Warning | 存在限制或跳过，但不属于故障 | 已跳过：存在未提交修改 |
| Error | 任务执行失败，需要关注 | 拉取失败：远端鉴权失败 |
| Fatal | 应用级严重问题 | Git 环境不可用 |

### 2.2 用户侧表达原则

- **Info**：简短确认
- **Warning**：说明"为什么没执行"
- **Error**：说明"为什么失败、用户可以做什么"
- **Fatal**：说明"当前无法继续使用的原因"

```json
  "message": "当前分支无法 fast-forward，请先手动处理分支差异。",
  "action": "打开仓库处理后再重试",
  "detail": "git pull --ff-only exited with code 1",
  "repoId": "repo_xxx",
  "taskId": "task_xxx",
  "retryable": false
}
```

### 4.2 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| code | string | 是 | 错误码 |
| level | string | 是 | 级别（info/warning/error/fatal） |
| title | string | 是 | 短标题 |
| message | string | 是 | 用户可见主要文案 |
| action | string | 否 | 建议动作 |
| detail | string | 否 | 调试信息摘要 |
| repoId | string | 否 | 关联仓库 ID |
| taskId | string | 否 | 关联任务 ID |
| retryable | boolean | 是 | 是否允许重试 |

## 五、文案规范原则

### 5.1 推荐句式

**成功类**：
- 同步完成
- 状态已刷新
- 配置已保存

**跳过类**：
- 已跳过：存在未提交修改
- 已跳过：未配置 upstream

**失败类**：
- 拉取失败：远端鉴权失败
- 状态读取失败：仓库路径不可访问

### 5.2 不推荐句式

- ❌ 操作异常，请稍后重试
- ❌ 未知错误
- ❌ 系统繁忙
- ❌ 发生异常
