# SyncDock v2.0.0 功能与页面使用说明：总览与仓库

## 一、总览页

### 1. 状态页

- 顶部指标卡显示仓库总数、成功、失败、警告、待同步
- 点击指标卡可切换过滤条件
- 仓库列表展示名称、归属、分支、最近同步时间与状态

### 2. 摘要页

- 最近一次任务：显示最近任务状态、耗时、结果汇总
- 最近失败仓库：快速查看失败原因
- 待处理与快捷处理：列出需要同步或需要关注的仓库

## 二、仓库页

### 1. 工作区

- 按分组切换仓库视角
- 支持同步全部、同步当前分组、强制同步
- 分组右上角 `+` 用于新增分组，`-` 用于删除分组
- 删除分组时，可多选分组统一删除

### 2. 清单

- 支持按关键词、分组、状态筛选
- 支持多选仓库
- 列表状态文案与总览页保持一致

### 3. 日志

- 默认显示全部仓库日志
- 选择某个仓库后切到单仓库日志
- 支持日志搜索、级别过滤、导出

## 三、仓库详情页

### 顶部操作区

- 保存信息
- 立即同步
- 强制同步
- 刷新状态
- 打开目录
- 复制路径
- 移除仓库

### 左侧编辑卡

- 仓库名称
- 分组
- 仓库归属
- 是否启用同步
- 仓库路径
- 备注

### 右侧状态卡

- remote URL
- 仓库归属
- 当前分支
- upstream
- 最近同步
- 最近结果
- 状态说明

### 底部同步日志

- 仅展示当前仓库日志
- 支持复制和导出
