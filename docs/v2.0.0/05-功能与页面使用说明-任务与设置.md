# SyncDock v2.0.0 功能与页面使用说明：任务与设置

## 一、任务页

### 1. 概览

- 当前任务：显示运行中的后台任务
- 今日任务：只展示当天任务，分为进行中、已完成、已取消
- 进行中的任务支持取消
- 进度条使用持续流动高光效果表示执行中

### 2. 历史任务

- 支持任务搜索
- 支持按结果筛选
- 支持按日期筛选
- 列表采用紧凑行式布局，点击可查看详情

### 3. 日志中心

- 先选择任务，再查看任务日志
- 支持搜索任务日志、按警告/错误筛选
- 支持导出任务日志

## 二、设置页

### 1. 常规

- 默认启动页
- 界面主题
- 语言
- 窗口关闭行为

### 2. 同步

- 同步模式
- 并发数
- 命令超时
- 跳过未跟踪文件
- 自动重试瞬时失败

### 3. 路径与目录

- 配置目录
- 日志目录
- 日志保留天数
- 是否保留调试日志
- 仓库配置导入导出

- 检查更新
- 打开 GitHub 仓库
- 反馈问题
- 导出诊断配置
