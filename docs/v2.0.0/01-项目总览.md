# SyncDock v2.0.0 项目总览

## 项目定位

SyncDock 是一款面向多仓库开发场景的桌面同步工作台，核心目标是把“查看状态、刷新状态、执行同步、追踪任务、排查问题”收敛到一个统一界面中完成。

## 目标用户

- 同时维护多个 Git 仓库的个人开发者
- 需要在多台设备间同步工作目录的工程师
- 需要统一查看仓库状态、任务结果和日志的技术负责人

## 核心价值

- 降低多仓库日常 `fetch/pull/status` 的重复成本
- 用后台任务方式执行耗时操作，不阻塞桌面使用
- 用结构化状态、错误码和日志，提升定位效率
- 用统一配置与导入导出能力，支持跨设备迁移

## v2.0.0 范围

- 桌面端四大主页面：总览、仓库、任务、设置
- 仓库详情双栏布局与顶部操作区
- 后台同步与后台刷新状态
- 任务进度日志与今日任务概览
- 仓库日志中心、任务日志中心、错误码透出
- 配置目录、日志目录、仓库配置导入导出

## 不在本版本范围

- macOS 安装包交付
- 自动扫描目录导入
- 默认扫描目录、扫描深度、忽略目录设置项
- 云端账户、多用户协作、远程服务端

## 页面结构

- 总览：查看仓库总体状态、最近任务、待处理项
- 仓库：
  - 工作区：按分组查看与批量同步
  - 清单：列表筛选与快速定位
  - 日志：查看聚合仓库日志或单仓库日志
- 任务：
  - 概览：当前任务、今日任务
  - 历史任务：筛选与详情查看
  - 日志中心：查看选中任务日志
- 设置：
  - 常规
  - 同步
  - 路径与目录
  - 关于
