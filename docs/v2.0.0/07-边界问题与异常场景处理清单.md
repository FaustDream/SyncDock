# SyncDock v2.0.0 边界问题与异常场景处理清单

## 仓库层

- 仓库路径不存在
- 路径存在但不是 Git 仓库
- 仓库缺少 upstream
- Detached HEAD
- 本地有未提交修改
- 本地有未跟踪文件
- 仓库正在 rebase / merge / cherry-pick
- 远端领先，本地落后
- 本地领先，远端未同步

## 同步层

- fetch 失败
- pull 失败
- force 模式覆盖本地变更
- 网络瞬断
- Git 锁文件冲突
- 命令超时
- 用户主动取消任务

## 配置与存储层

- 配置目录不可写
- 日志目录不可写
- 导入配置时路径失效
- 导入配置时仓库路径冲突
- 导入配置时日志目录无效

## UI 与交互层

- 后台任务执行中切换页面
- 日志超长导致卡顿
- 多层滚动容器引发体验混乱
- 文案编码异常或乱码

## 处理原则

- 优先保守，不隐式覆盖用户本地数据
- 可预检的先预检，再执行
- 可恢复的错误提供建议动作
- 所有关键失败尽量透出错误码
