# SyncDock v2.0.0 故障排查指南

## 1. 应用能打开，但无法同步

- 检查 Git 环境是否为“可用”
- 检查仓库是否配置 upstream
- 检查仓库是否存在未提交或未跟踪文件
- 到任务日志或仓库日志搜索 `SD-`

## 2. 点击同步或刷新后界面卡住

- 确认是否已进入后台任务模式
- 到任务页查看是否生成了当前任务
- 若无任务，检查前端事件监听与命令返回

## 3. 仓库状态不准确

- 先点击“刷新状态”
- 确认仓库路径仍存在
- 检查 Git 说明和当前分支是否正常

## 4. 日志导出失败

- 检查目标保存路径是否有权限
- 检查当前任务或仓库是否已选择

## 5. 配置导入后仓库异常

- 先查看导入预检中的冲突和无效路径
- 检查路径前缀替换是否正确
- 必要时恢复导入前备份

## 6. Windows 免安装版无法运行

- 确认系统已安装 Microsoft Edge WebView2 Runtime
- 确认未被安全软件拦截
- 尝试以普通用户方式直接运行主程序

## 7. 安装版无法安装

- 检查安装包是否完整下载
- 检查系统权限和安全策略
- 重新生成 NSIS 安装包后再验证
