# SyncDock v2.0.0 错误码与提示文案规范

## 目标

- 让用户知道“出了什么问题”
- 让开发和测试知道“该去哪里排查”
- 让日志和界面提示可互相对应

## 规范

### 错误码格式

- 前缀统一为 `SD-`
- 模块示例：
  - `SD-GIT-xxx`
  - `SD-SYNC-xxx`
  - `SD-CFG-xxx`
  - `SD-MIG-xxx`

### 文案结构

- 标题：一句话结论
- 正文：当前问题描述
- 细节：技术上下文或路径
- 动作：建议用户下一步怎么做

## 典型提示示例

### 网络失败

- 错误码：`SD-GIT-002`
- 标题：获取远端信息失败
- 文案：远端仓库暂时不可访问，已停止当前仓库同步。
- 动作：请检查网络连接或稍后重试。

### 锁文件冲突

- 错误码：`SD-GIT-008`
- 标题：Git 锁文件冲突
- 文案：仓库当前可能被其他 Git 进程占用。
- 动作：请关闭其他 Git 工具后重试。

### 命令超时

- 错误码：`SD-SYNC-004`
- 标题：同步命令执行超时
- 文案：当前仓库在限定时间内未完成操作。
- 动作：可提高命令超时设置后重新执行。

## UI 展示要求

- 通知区展示标题和错误码
- 日志行展示错误级别和错误码
- 详情页与日志中心可通过错误码搜索
