# SyncDock v2.0.0 常见 Bug 风险与排除清单

## 一、前端风险

- 页面文本乱码
  - 排查：检查文件编码、历史坏字符、字符串常量来源
- 多个滚动容器叠加
  - 排查：检查页面主滚动区和局部滚动区是否重复设置 `overflow`
- 输入框尺寸不统一
  - 排查：检查页面级表单样式覆盖是否遗漏
- 任务列表拥挤或重叠
  - 排查：检查列表栅格列定义与移动端断点样式

## 二、后端风险

- 后台任务未真正异步执行
  - 排查：检查命令是否立即返回任务记录，而不是等待 Git 操作结束
- 错误码未写入日志
  - 排查：检查 warning/error 写日志时是否拼接 `SD-...`
- 配置迁移后字段残留
  - 排查：检查类型、默认值、序列化模型、导入导出差异比对

## 三、发布风险

- 版本号前后端不一致
  - 排查：检查 `package.json`、`Cargo.toml`、`tauri.conf.json`
- 免安装版缺少说明文件
  - 排查：检查便携包目录和压缩步骤
- 安装版打包失败
  - 排查：检查 Tauri/NSIS 依赖、Windows 构建环境

## 四、回归建议

- 回归仓库新增、编辑、删除
- 回归后台刷新与后台同步
- 回归任务取消
- 回归日志搜索、导出、错误码展示
- 回归设置页路径切换与配置导入导出
