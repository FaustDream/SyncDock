# 同步坞常见 Bug 风险与排查清单

## 一、文档目的

本文档整理同步坞开发过程中可能遇到的常见 Bug 风险点，以及对应的排查方法和预防措施，帮助开发者快速定位问题。

## 二、环境与依赖类 Bug

### 2.1 Git 环境问题

#### Bug 风险：Git 未找到

| 项目 | 内容 |
|------|------|
| **现象** | 提示"未检测到 Git" |
| **原因** | Git 未安装或不在 PATH 中 |
| **排查步骤** | 1. 检查 Git 是否安装<br>2. 检查 PATH 环境变量<br>3. 在终端执行 `git --version` |
| **解决方案** | 安装 Git 或添加到 PATH |
| **预防措施** | 应用启动时检测并提示 |

#### Bug 风险：Git 版本过低

| 项目 | 内容 |
|------|------|
| **现象** | 部分 Git 命令失败 |
| **原因** | Git 版本 < 2.0 |
| **排查步骤** | 1. 检查 Git 版本<br>2. 查看具体失败的命令 |
| **解决方案** | 升级 Git |
| **预防措施** | 启动时检测版本并提示 |

#### Bug 风险：Git 执行权限问题

| 项目 | 内容 |
|------|------|
| **现象** | 提示"Git 不可执行" |
| **原因** | 权限不足或文件损坏 |
| **排查步骤** | 1. 检查 git 可执行文件权限<br>2. 尝试手动执行 git 命令 |
| **解决方案** | 修复权限或重新安装 Git |
| **预防措施** | 捕获权限异常并提示 |

---

### 2.2 配置目录问题

#### Bug 风险：配置目录不可写

| 项目 | 内容 |
|------|------|
| **现象** | 配置保存失败 |
| **原因** | 权限不足或磁盘已满 |
| **排查步骤** | 1. 检查配置目录权限<br>2. 检查磁盘空间<br>3. 查看应用日志 |
| **解决方案** | 修复权限或更换配置目录 |
| **预防措施** | 启动时检测写入权限 |

#### Bug 风险：配置文件损坏

| 项目 | 内容 |
|------|------|
| **现象** | 应用无法启动或配置丢失 |
| **原因** | JSON 格式错误或文件损坏 |
| **排查步骤** | 1. 检查配置文件内容<br>2. 验证 JSON 格式<br>3. 查看错误日志 |
| **解决方案** | 删除损坏文件或恢复备份 |
| **预防措施** | 配置写入前备份，使用原子写入 |

## 三、仓库管理类 Bug

### 3.1 路径问题

#### Bug 风险：中文路径乱码

| 项目 | 内容 |
|------|------|
| **现象** | 中文路径显示乱码或无法访问 |
| **原因** | 编码问题 |
| **排查步骤** | 1. 检查系统编码设置<br>2. 检查 Git 输出编码<br>3. 查看应用日志中的路径 |
| **解决方案** | 统一使用 UTF-8 编码 |
| **预防措施** | 所有路径处理使用 UTF-8 |

#### Bug 风险：路径包含空格

| 项目 | 内容 |
|------|------|
| **现象** | 命令执行失败 |
| **原因** | 路径未加引号 |
| **排查步骤** | 1. 查看命令日志<br>2. 检查路径是否包含空格 |
| **解决方案** | 在命令中为路径加引号 |
| **预防措施** | 所有路径参数统一加引号 |

#### Bug 风险：路径过长

| 项目 | 内容 |
|------|------|
| **现象** | Windows 上无法访问路径 |
| **原因** | 超过 Windows 路径长度限制 |
| **排查步骤** | 1. 检查路径长度<br>2. 查看是否在 Windows 上 |
| **解决方案** | 启用 Windows 长路径支持或缩短路径 |
| **预防措施** | 提示用户路径过长 |

### 3.2 仓库识别问题

#### Bug 风险：仓库重复添加

| 项目 | 内容 |
|------|------|
| **现象** | 同一仓库被添加多次 |
| **原因** | 路径规范化不一致 |
| **排查步骤** | 1. 检查路径比较逻辑<br>2. 查看数据库中的仓库路径 |
| **解决方案** | 使用统一的路径规范化函数 |
| **预防措施** | 添加前去重检查 |

#### Bug 风险：仓库状态识别错误

| 项目 | 内容 |
|------|------|
| **现象** | 状态显示与实际不符 |
| **原因** | Git 命令解析错误 |
| **排查步骤** | 1. 手动执行相同的 Git 命令<br>2. 检查命令输出解析逻辑<br>3. 查看原始命令输出 |
| **解决方案** | 修正解析逻辑 |
| **预防措施** | 添加解析失败的处理 |

## 四、同步流程类 Bug

### 4.1 同步状态问题

#### Bug 风险：同步卡住不动

| 项目 | 内容 |
|------|------|
| **现象** | 进度条不动，仓库一直显示"同步中" |
| **原因** | Git 命令超时未处理 |
| **排查步骤** | 1. 检查是否有 Git 进程卡住<br>2. 查看应用日志<br>3. 检查超时配置 |
| **解决方案** | 添加超时机制，杀死超时进程 |
| **预防措施** | 所有 Git 命令添加超时控制 |

#### Bug 风险：同步结果不准确

| 项目 | 内容 |
|------|------|
| **现象** | 成功/失败数量不对 |
| **原因** | 状态统计逻辑错误 |
| **排查步骤** | 1. 检查状态统计代码<br>2. 查看每个仓库的实际结果<br>3. 验证状态分类逻辑 |
| **解决方案** | 修正统计逻辑 |
| **预防措施** | 添加状态统计的单元测试 |

### 4.2 并发问题

#### Bug 风险：并发同步冲突

| 项目 | 内容 |
|------|------|
| **现象** | 同一仓库被多次同步 |
| **原因** | 并发控制失效 |
| **排查步骤** | 1. 检查任务锁逻辑<br>2. 查看并发配置<br>3. 检查任务队列 |
| **解决方案** | 加强并发控制 |
| **预防措施** | 使用全局任务锁 |

#### Bug 风险：内存占用过高

| 项目 | 内容 |
|------|------|
| **现象** | 应用内存持续增长 |
| **原因** | 未释放资源或日志过多 |
| **排查步骤** | 1. 检查内存使用情况<br>2. 查看日志缓冲区<br>3. 检查事件监听器 |
| **解决方案** | 及时释放资源，限制日志缓冲 |
| **预防措施** | 定期清理，限制缓冲区大小 |

| **解决方案** | 添加网络超时捕获 |

#### Bug 风险：代理配置问题

| **现象** | 无法访问 GitHub |

| **预防措施** | 捕获鉴权错误并提示 |

#### Bug 风险：HTTPS 凭证失效

| 项目 | 内容 |
|------|------|
| **现象** | 提示"凭证失效" |
| **原因** | 凭证过期或被撤销 |
| **排查步骤** | 1. 检查 Git Credential Manager<br>2. 测试 HTTPS 访问<br>3. 查看鉴权错误 |
| **解决方案** | 更新凭证 |
| **预防措施** | 捕获凭证错误并提示 |

## 八、排查工具与方法

### 8.1 日志查看

**应用日志位置**：
- Windows: `%APPDATA%/com.syncdock.desktop/logs/app.log`
- macOS: `~/Library/Application Support/com.syncdock.desktop/logs/app.log`
- Linux: `~/.config/com.syncdock.desktop/logs/app.log`

**任务日志**：
- `logs/task_YYYYMMDD_HHMMSS.log`

### 8.2 调试模式

**开启方法**：
1. 进入设置页
2. 找到"同步设置"
3. 开启"显示调试日志"
4. 重新执行操作
5. 查看详细日志

### 8.3 常用 Git 诊断命令

```bash
# 检查 Git 版本
git --version

# 测试 SSH 连接
ssh -T git@github.com

# 检查仓库状态
git status

# 查看远程仓库
git remote -v

# 测试 fetch
git fetch --dry-run
```
