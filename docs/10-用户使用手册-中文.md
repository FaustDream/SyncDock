## 快速开始

### 安装

1. 下载最新版本安装包
2. Windows: 双击 `.msi` 文件安装
3. macOS: 拖动应用到 Applications 文件夹
4. Linux: 使用 `.deb` 或 `.rpm` 包安装

### 首次使用

1. 确保已安装 Git（版本 ≥ 2.0）
2. 启动同步坞
3. 点击"扫描导入"或"添加仓库"
4. 选择本地仓库目录
5. 开始使用

## 功能说明

### 仓库管理

#### 扫描导入

**功能**：自动扫描本地目录，识别 Git 仓库

**步骤**：
1. 点击"扫描导入"按钮
2. 选择要扫描的根目录
3. 设置扫描深度（默认 4 层）
4. 点击"开始扫描"
5. 勾选要导入的仓库
6. 为每个仓库设置名称和分组
7. 点击"导入选中仓库"

**提示**：
- 已存在的仓库会自动去重
- 建议将相关仓库归入同一分组

#### 添加仓库

**功能**：手动添加单个仓库

**步骤**：
1. 点击"添加仓库"按钮
2. 选择仓库目录
3. 设置仓库名称、分组、备注
4. 点击"添加"

#### 克隆仓库

**功能**：从远端 URL 克隆新仓库

**步骤**：
1. 点击"添加仓库" → "克隆仓库"
2. 输入远端 URL
3. 选择目标目录
4. 设置名称和分组
5. 点击"克隆"

### 同步功能

#### 一键同步

**功能**：同步所有启用仓库

**步骤**：
1. 点击右上角"同步全部"按钮
2. 查看同步进度
3. 完成后查看结果统计

**跳过场景**：
- 存在未提交修改
- 未配置 upstream
- 处于 rebase/merge 中
- detached HEAD 状态

#### 分组同步

**功能**：仅同步指定分组

**步骤**：
1. 切换到目标分组
2. 点击"同步当前分组"

#### 选中同步

**功能**：同步勾选的仓库

**步骤**：
1. 在清单视图勾选仓库
2. 点击"同步"按钮

---

### 状态查看

#### 仓库状态

**状态类型**：
- **正常**：已同步或无需同步（绿色）
- **改动**：存在未提交修改（黄色）
- **待同步**：behind > 0（黄色）
- **异常**：仓库损坏或错误（红色）
- **跳过**：因保护规则跳过（灰色）
- **同步中**：正在执行（蓝色）

#### 详情查看

点击仓库名称进入详情页，可查看：
- 基本信息（路径、分支、远端）
- 同步结果
- 最近日志
- 快捷操作

---

### 设置

#### 常规设置

- **默认视图**：启动时显示的页面
- **主题模式**：浅色/深色/跟随系统
- **语言**：中文/英文

#### 同步设置

- **并发数**：同时同步的仓库数量（默认 4）
- **超时时间**：命令执行超时秒数（默认 60）
- **跳过未跟踪文件**：是否跳过包含未跟踪文件的仓库
- **调试日志**：记录详细调试信息

#### 路径设置

- **配置目录**：配置文件存储位置
- **日志目录**：日志文件存储位置
- **默认扫描目录**：扫描时的默认起始目录

---

### 配置导入导出

#### 导出配置

**功能**：备份仓库列表和设置

**步骤**：
1. 进入"设置" → "仓库"
2. 点击"导出配置"
3. 选择保存位置
4. 生成 JSON 文件

#### 导入配置

**功能**：恢复或迁移配置

**步骤**：
1. 进入"设置" → "仓库"
2. 点击"导入配置"
3. 选择配置文件
4. 预览冲突和变更
5. 选择导入策略（merge/overwrite）
6. 确认导入

**跨设备迁移**：
1. 在原设备导出配置
2. 在新设备导入配置
3. 使用"路径前缀替换"调整路径

## 常见问题

### Q: 为什么仓库被跳过？

**可能原因**：
1. 存在未提交修改 - 提交或暂存后重试
2. 未配置 upstream - 手动设置上游分支
3. 处于 rebase/merge 中 - 完成或中止操作
4. detached HEAD - 切回正常分支

### Q: 如何处理鉴权失败？

**SSH 方式**：
1. 检查 SSH key 是否配置
2. 确保 ssh-agent 正在运行
3. 测试 SSH 连接：`ssh -T git@github.com`

**HTTPS 方式**：
1. 检查凭证是否过期
2. 更新 Git Credential Manager
3. 重新输入用户名密码

### Q: 如何更新仓库路径？

仓库路径无法直接修改，需要：
1. 删除原仓库记录
2. 重新添加新路径

### Q: 日志可以删除吗？

可以，日志会按配置天数自动清理（默认 30 天）。
也可在"设置" → "路径"中手动清理。

## 最佳实践

### 仓库分组建议

- **工作**：工作相关项目
- **个人**：个人项目
- **文档**：文档类仓库
- **配置**：配置文件仓库

### 同步策略建议

1. **定期同步**：每天开始工作时同步一次
2. **检查状态**：同步前查看是否有改动
3. **处理异常**：及时处理跳过和失败的仓库
4. **备份配置**：定期导出配置备份
