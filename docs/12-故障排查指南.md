# 同步坞故障排查指南

> 版本：v1.0  
> 更新时间：2026-04-06

---

## 一、环境问题

### 1.1 Git 未检测到

**现象**：提示"未检测到 Git"

**排查步骤**：
1. 打开终端/命令行
2. 执行 `git --version`
3. 检查是否返回版本号

**解决方案**：
- 如果命令不存在：安装 Git
- 如果命令存在但仍提示：检查 PATH 环境变量

**Git 安装地址**：
- Windows: https://git-scm.com/download/win
- macOS: `brew install git`
- Linux: `sudo apt install git` 或 `sudo yum install git`

---

### 1.2 Git 版本过低

**现象**：提示"Git 版本过低"

**最低要求**：Git 2.0+

**排查步骤**：
```bash
git --version
```

**解决方案**：
升级 Git 到最新版本

---

### 1.3 应用无法启动

**可能原因**：
1. 配置文件损坏
2. 权限不足
3. 缺少依赖

**排查步骤**：
1. 检查应用日志（见日志位置章节）
2. 删除配置目录重新启动
3. 以管理员权限运行

**配置目录位置**：
- Windows: `%APPDATA%/com.syncdock.desktop/`
- macOS: `~/Library/Application Support/com.syncdock.desktop/`
- Linux: `~/.config/com.syncdock.desktop/`

---

## 二、仓库问题

### 2.1 仓库路径不存在

**现象**：提示"仓库路径不存在"

**排查步骤**：
1. 检查仓库目录是否被删除或移动
2. 检查外置硬盘是否连接
3. 检查网络路径是否可访问

**解决方案**：
- 删除失效的仓库记录
- 重新添加正确路径
- 连接设备后重试

---

### 2.2 不是有效仓库

**现象**：提示"不是有效仓库"

**排查步骤**：
```bash
cd <仓库路径>
git status
```

**解决方案**：
- 确认目录包含 `.git` 文件夹
- 如果是裸仓库，不支持同步
- 如果 `.git` 损坏，需要修复仓库

---

### 2.3 仓库状态异常

**现象**：无法读取仓库状态

**排查步骤**：
```bash
cd <仓库路径>
git status
git branch
git remote -v
```

**解决方案**：
- 检查 Git 仓库是否损坏
- 尝试手动执行 Git 命令
- 查看 Git 错误信息

---

## 三、同步问题

### 3.1 仓库被跳过

#### 情况1：存在未提交修改

**现象**：提示"存在未提交修改，已跳过"

**排查步骤**：
```bash
git status
```

**解决方案**：
```bash
# 提交修改
git add .
git commit -m "message"

# 或暂存修改
git stash
```

---

#### 情况2：未配置 upstream

**现象**：提示"未配置 upstream，已跳过"

**排查步骤**：
```bash
git branch -vv
```

**解决方案**：
```bash
# 设置上游分支
git branch --set-upstream-to=origin/main main

# 或首次推送时设置
git push -u origin main
```

---

#### 情况3：detached HEAD

**现象**：提示"当前处于 detached HEAD"

**排查步骤**：
```bash
git branch
git log --oneline -5
```

**解决方案**：
```bash
# 切回正常分支
git checkout main
git checkout <branch-name>
```

---

#### 情况4：rebase/merge 中

**现象**：提示"正在 rebase 或 merge 中"

**排查步骤**：
```bash
ls .git/rebase-merge
ls .git/rebase-apply
ls .git/MERGE_HEAD
```

**解决方案**：
```bash
# 完成 rebase
git rebase --continue

# 或中止 rebase
git rebase --abort

# 完成 merge
git commit

# 或中止 merge
git merge --abort
```

---

### 3.2 同步失败

#### 情况1：无法快进

**现象**：提示"无法 fast-forward"

**原因**：本地和远端都有提交，产生分叉

**排查步骤**：
```bash
git log --oneline --graph --all -10
```

**解决方案**：
```bash
# 手动合并
git pull

# 或变基
git pull --rebase

# 解决冲突后
git add .
git rebase --continue
```

---

#### 情况2：同步超时

**现象**：提示"同步超时"

**原因**：
- 网络慢
- 仓库过大
- 超时设置过短

**解决方案**：
1. 增加超时时间（设置 → 同步设置 → 超时时间）
2. 检查网络连接
3. 手动同步该仓库

---

### 3.3 同步卡住

**现象**：进度条不动

**排查步骤**：
1. 检查是否有 Git 进程卡住
2. 查看应用日志
3. 检查网络连接

**解决方案**：
1. 点击"取消"按钮
2. 重启应用
3. 手动在该仓库执行 `git fetch`

---

## 四、鉴权问题

### 4.1 SSH 鉴权失败

**现象**：提示"SSH 鉴权失败"

**排查步骤**：
```bash
# 测试 SSH 连接
ssh -T git@github.com

# 检查 SSH key
ls ~/.ssh/id_rsa.pub

# 检查 ssh-agent
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_rsa
```

**解决方案**：
1. 生成 SSH key：
   ```bash
   ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
   ```
2. 添加到 GitHub/GitLab
3. 启动 ssh-agent
4. 添加 key 到 agent

---

### 4.2 HTTPS 凭证失效

**现象**：提示"凭证失效"

**排查步骤**：
1. 检查 Git Credential Manager
2. 测试 HTTPS 访问

**解决方案**：
1. 更新凭证：
   ```bash
   git config --global credential.helper manager
   ```
2. 清除旧凭证：
   - Windows: 控制面板 → 凭据管理器
   - macOS: Keychain Access
3. 重新输入用户名密码

---

## 五、网络问题

### 5.1 无法连接远端

**现象**：提示"网络连接失败"

**排查步骤**：
```bash
# 测试连接
ping github.com

# 测试 Git 访问
git ls-remote https://github.com/user/repo.git
```

**解决方案**：
1. 检查网络连接
2. 检查防火墙设置
3. 检查代理配置：
   ```bash
   git config --global http.proxy
   ```

---

### 5.2 网络超时

**现象**：提示"网络超时"

**解决方案**：
1. 检查网络速度
2. 使用代理或 VPN
3. 增加超时时间

---

## 六、配置问题

### 6.1 配置保存失败

**现象**：提示"配置保存失败"

**排查步骤**：
1. 检查磁盘空间
2. 检查配置目录权限
3. 查看应用日志

**解决方案**：
1. 释放磁盘空间
2. 修复目录权限
3. 更换配置目录

---

### 6.2 配置导入失败

**现象**：提示"导入文件格式无效"

**排查步骤**：
1. 检查文件是否为 JSON 格式
2. 检查文件是否损坏
3. 查看导入预览错误

**解决方案**：
1. 重新导出配置
2. 检查 JSON 格式
3. 手动修复或使用备份

---

## 七、日志查看

### 7.1 应用日志

**位置**：见日志位置章节

**文件**：`app.log`

**内容**：
- 应用启动信息
- Git 环境检测结果
- 错误和异常信息

### 7.2 任务日志

**文件**：`task_YYYYMMDD_HHMMSS.log`

**内容**：
- 同步任务执行记录
- 每个仓库的同步结果
- Git 命令输出

### 7.3 调试模式

**开启方法**：
1. 设置 → 同步设置
2. 开启"显示调试日志"
3. 重新执行操作
4. 查看详细日志

## 八、性能问题

### 8.1 应用运行缓慢

**可能原因**：
- 仓库数量过多
- 日志文件过大
- 内存占用高

**解决方案**：
1. 减少仓库数量（分组管理）
2. 清理旧日志
3. 重启应用

---

### 8.2 同步速度慢

**可能原因**：
- 网络速度慢
- 仓库过大
- 并发数过高

**解决方案**：
1. 检查网络连接
2. 减少并发数
3. 使用代理加速

---

## 九、数据恢复

### 9.1 配置丢失

**解决方案**：
