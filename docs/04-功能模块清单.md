## 四、明确不纳入首版的功能

| 功能 | 说明 | 原因 |
|------|------|------|
| 自动 commit | 自动提交本地修改 | 违背保守原则 |
| 自动 push | 自动推送到远端 | 风险过高 |
| 冲突自动解决 | 自动合并冲突 | 技术复杂度高 |
| 自动 stash | 自动暂存修改 | 可能丢失工作区状态 |
| GitHub 登录 | OAuth 登录 GitHub | 增加复杂度 |
| 云端配置同步 | 跨设备云端同步 | 需要后端服务 |
| 团队协作 | 共享工作区 | 产品定位不符 |
| 完整提交树 | Git 图谱展示 | 超出工具边界 |
| 代码编辑 | IDE 能力 | 超出工具边界 |
